# 새 서버 오픈 매뉴얼 (v2)

서버를 늘릴 때마다 이 순서대로 하면 된다. **도스창 도구도, GitHub 등록도 필요 없다.**

| | 할 일 | 시간 |
|---|---|---|
| ✋ | Contabo 주문 | 5분 |
| 🤖 | 서버에 명령 1줄 → 자동 설치 | 5~10분 |
| ✋ | 브라우저로 `https://서버IP` 접속 → 비밀번호 변경 | 1분 |
| ✋ | 폴더 만들고 비디오·음악 올리기 | 파일 양에 따라 |
| ✋ | 라이브 추가 (이름 · 스트림 키 · 폴더 체크) → **저장하고 시작** | 1분 |

## 1. Contabo 주문

| 항목 | 선택 |
|---|---|
| 상품 | Cloud VPS 4 (4 vCPU / 8GB) |
| 리전 | European Union |
| 이미지 | **Ubuntu 24.04** (22.04도 가능) |
| 로그인 | root 비밀번호 설정 → 메모. SSH 키 칸이 있으면 PC 공개키도 넣는다(선택) |

패널에서 상태가 **Running**이 되면 **IP Address**를 복사한다.

## 2. 설치 (명령 1줄)

PC의 PowerShell에서 서버에 접속한다 (처음 묻는 질문은 `yes`, 비밀번호는 화면에 안 보이는 게 정상):

```powershell
ssh root@서버IP
```

서버에 들어가면 이 한 줄을 붙여넣는다:

```bash
curl -fsSL https://raw.githubusercontent.com/alligogo/LiveMax/main/get.sh | bash
```

끝나면 초록 박스에 이렇게 나온다. **비밀번호를 메모한다.**

```
  LiveMax 설치 완료
  접속:   https://서버IP
  아이디: admin
  초기 비밀번호: xxxxxxxxxxxxxxxxxxxx
```

> "재부팅 권장"이 함께 나오면 `reboot` 한 번 하고 1분 뒤 진행한다 (LiveMax 는 자동으로 다시 켜진다).

## 3. 대시보드 접속

브라우저에서 `https://서버IP` → 아이디 `admin` + 초기 비밀번호 → **새 비밀번호(12자 이상)로 변경**.

- 설치 직후 1~2분은 인증서 발급 중이라 "안전하지 않음"이 보일 수 있다. 잠시 뒤 새로고침한다.
- 폰에서도 같은 주소로 들어간다. 즐겨찾기에 서버별로 저장해 두면 편하다.

## 4. 미디어 올리기

1. PC에서 원본을 **`LiveMax-Convert.bat`에 끌어다 놓아** 규격대로 변환한다 (아래 "PC 변환기").
2. 대시보드 **비디오** 탭 → 폴더 만들기 → 폴더 선택 → `LiveMax_변환` 폴더의 MP4 를 끌어다 놓기
3. **음악** 탭도 같은 방식으로 M4A 를 올린다.
4. 올린 파일은 자동으로 규격 검사를 거친다. 통과하면 목록에, 실패하면 아래 **검증 실패**에 이유가 나온다.

큰 파일도 업로드가 끊기면 **이어서** 올라간다 (같은 파일을 다시 끌어다 놓으면 남은 부분만).

## 5. 라이브 추가

**라이브** 탭 → **+ 라이브 추가**

| 칸 | 넣을 것 |
|---|---|
| 이름 | 아무거나 (예: 재즈 색소폰 24/7) |
| 스트림 키 | 유튜브 스튜디오 → 라이브 스트리밍 → 스트림 키 (라이브마다 다른 키) |
| 비디오 폴더 / 음악 폴더 | 체크 (여러 개 가능) |
| 재생 방식 | 그대로 (중복방지 랜덤) |
| 타이머 | 끄기(24시간 계속) / 방송 시간(예: 11시간 50분, 반복 가능) / 종료 시각 |

**저장하고 시작** → 몇 초 뒤 카드가 ● 정상으로 바뀌면 송출 중이다.

유튜브 스트림 설정 (라이브마다):

| 쓰는 방식 | 자동 시작 | 자동 중지 |
|---|---|---|
| 타이머 끔 — 하나의 방송을 계속 | 켬 | **끔** (재시작 공백에 방송이 끝나지 않게) |
| 타이머 켬 — 12시간 다시보기를 남김 | 켬 | **켬** (송출이 멈추면 방송 종료 → 다시보기 저장) |

타이머 + 자동 중지를 쓸 때는 처음 한 번 **재시작 버튼**을 눌러 2~3초 공백에도 방송이 이어지는지 유튜브 스튜디오에서 확인해 두자.

## 평소 운영 (전부 웹에서)

| 하고 싶은 것 | 어디서 |
|---|---|
| 라이브 시작·정지·재시작 | 라이브 카드의 버튼 |
| 폴더·재생 방식·키 바꾸기 | 카드의 ✎ → **저장하고 지금 적용** (비디오만 바뀌면 2~3초, 음악이 바뀌면 약 8초 끊겼다가 복귀) |
| 타이머 바꾸기 | 카드의 ✎ → 타이머 → 저장 (재시작 없이 바로 반영) |
| 휴대폰 알림 | 설정 → 모바일 알림 (Pushbullet 토큰 입력, 보낼 종류 선택) |
| 로그 보기 | 카드의 "로그" |
| 새 버전으로 업데이트 | 설정 → **최신 버전으로 업데이트** |
| 서버 재부팅 필요 알림 | 알림에 뜨면 한가한 시간에 서버에서 `reboot` |
| 일일 자동 재시작 시각 | 설정 → 송출 설정 (내 시간 기준) |
| 다른 서버로 라이브 설정 복사 | 설정 → 내보내기 → 새 서버에서 가져오기 → 키 입력 |
| 비밀번호 분실 | 서버에서 `sudo livemax password` |

## PC 변환기 (`tools/windows/LiveMax-Convert.bat`)

GitHub 저장소 → Code → Download ZIP → 압축 풀기 → `tools/windows/LiveMax-Convert.bat` (바탕화면에 바로 가기 추천).

- 영상·음악 파일이나 **폴더**를 끌어다 놓으면 원본 옆 `LiveMax_변환` 폴더에 같은 이름으로 생긴다.
- 영상: H.264 1080p 30fps 5500k, 키프레임 2초, 소리 제거 / 음원: AAC 128k 44.1kHz, -14 LUFS
- 100개가 넘으면 폴더째 끌어다 놓는다. ffmpeg 가 필요하다 (`winget install Gyan.FFmpeg`).

## 서버에서 쓰는 명령 (가끔)

```bash
livemax status      # 상태
livemax logs -f     # 실시간 로그
sudo livemax update # 업데이트 (웹 버튼과 같음)
sudo livemax password
```
